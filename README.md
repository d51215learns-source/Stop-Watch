Stopwatch App (Jetpack Compose)

A smooth, animated stopwatch application built using Kotlin and Jetpack Compose.

#Features
- Start / Pause functionality
- Reset timer
- Millisecond precision
- Animated circular progress ring
- Clean gradient UI
- Modern minimal layout

#Tech Stack
- Kotlin
- Jetpack Compose
- Canvas drawing
- State management using `remember` & `mutableStateOf`
- Coroutines (`LaunchedEffect`)

#UI Highlights
- Gradient dark background
- Cyan animated progress ring
- Centered modern layout
- Smooth 60 FPS timer updates

#How to Run
1. Download the project
2. Open in Android Studio
3. Run on emulator or physical device
